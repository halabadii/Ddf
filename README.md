# شخصيتي — Android Final Project

تطبيق RPG لتطوير الذات، يعتمد على إدخال يومي واقعي وتحويله إلى مستويات وXP وشخصية تتغير بصريًا.

## المزايا
- شخصية RPG مرئية تتغير حسب متوسط التطور والمزاج.
- 12 مجالًا: الجسم، الصحة، النوم، العقل، التعلم، الانضباط، الثقة، العلاقات، المال، المهارات، الروح، الراحة.
- مستوى مستقل لكل مجال.
- مستوى إجمالي وXP.
- سلسلة أيام (Streak).
- تسجيل يومي يدوي.
- XP يُمنح عند حفظ اليوم، وليس عند تحريك المؤشر.
- حفظ محلي على الجهاز عبر SharedPreferences.
- واجهة عربية وDark UI.

## البناء
افتح المجلد في Android Studio ثم Build > Generate App Bundles or APKs > Generate APKs.

يتطلب Android SDK مناسبًا وGradle/Android Studio متصلًا بالإنترنت لتنزيل dependencies عند أول بناء.
